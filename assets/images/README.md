# Afbeeldingen

Plaats hier de echte screenshots van de demo-websites:

- `project-hairstudio.png` (aanbevolen: 1600 × 1200 px, JPG of PNG)
- `project-apex.png`

Vervang daarna in `index.html` de `.svg`-paden door de nieuwe bestanden.
Voorbeeld:

```html
<img src="assets/images/project-hairstudio.png" alt="...">
```

Tips:
- Gebruik relatieve paden (`assets/images/...`), geen absolute URL's.
- Houd bestandsnamen klein, zonder spaties.
- Comprimeer afbeeldingen voor snelle laadtijd.
